# GraphQL Lab — AppSync API Console — 5 Steps

This lab moves from the hand-rolled Express/GraphQL server used in the earlier labs to AWS AppSync's managed API console, exploring how a GraphQL API, its resolvers, and its underlying data source fit together in a managed service. Each step includes an estimated time and a short objective. Total time: ~38 min

1. [Create a GraphQL API - Query and Mutations](step-1.md) — 16 min
	- Objective: Create a GraphQL API in the AWS AppSync console and exercise it with queries and mutations.

2. [Update and Delete](step-2.md) — 8 min
	- Objective: Add update and delete operations to the AppSync API and test them in the console.

3. [Resolvers Overview](step-3.md) — 5 min
	- Objective: Understand how resolvers connect AppSync's GraphQL schema to a data source.

4. [System Architecture Overview](step-4.md) — 5 min
	- Objective: See how the AppSync API, its resolvers, and the underlying data source fit together end to end.

5. [Final Thoughts on AWS AppSync API Console](step-5.md) — 4 min
	- Objective: Review takeaways from working with a managed GraphQL API console versus a self-hosted server.
