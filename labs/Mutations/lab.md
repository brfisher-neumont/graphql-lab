# GraphQL Lab — Mutations — 6 Steps

This lab builds on the Getting Started lab by introducing mutations — write operations that create data — alongside a couple of new queries. Each step includes an estimated time and a short objective. Total time: ~40 min

1. [Introduction to Mutations](step-1.md) — 2 min
	- Objective: Understand what a `GraphQLObjectType` mutation is and how it differs from a query.

2. [Creating a Customer with Mutations](step-2.md) — 12 min
	- Objective: Add a `Mutation` root type with a resolver that creates a new `Customer`.

3. [Creating a FocusSession with Mutations](step-3.md) — 7 min
	- Objective: Add a mutation that creates a new `FocusSession`.

4. [Creating a Theme with Mutations](step-4.md) — 8 min
	- Objective: Add a mutation that creates a new `Theme`.

5. [Adding a FocusSession Query](step-5.md) — 6 min
	- Objective: Add a top-level query to fetch the `FocusSession`s created via mutation.

6. [Customers Query](step-6.md) — 5 min
	- Objective: Create a `customers` query so we can verify all the customers in the system.
